# Functional Requirements

## What are Functional Requirements?

Functional requirements define what the application should do. They describe the features and functionalities that users can interact with.

## Functional Requirements

### User Management

* User Registration
* User Login
* Forgot/Reset Password
* User Profile Management

### Study Management

* Create Study Goal
* Create Subjects
* Create Topics
* Organize Topics by Subject

### Task Management

* Automatic Daily Task Generation
* Manual Task Creation
* Edit/Delete Tasks
* Automatic Rescheduling of Incomplete Tasks

### Progress Tracking

* Mark Tasks as Completed
* Track Daily Progress
* Track Subject-wise Progress
* Study Analytics Dashboard

### AI Features

* AI Study Planning
* AI Doubt Assistance
* AI Study Recommendations
